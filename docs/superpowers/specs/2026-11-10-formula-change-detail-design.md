# 配方变更详情：流程卡可视化与合并对比

用户已选择 A 合并对比方案，并要求流程卡详情参照打样任务详情。

- 上方：流程卡号、订字色号与处理状态；复用布料示意和关键资料，补充米数、成品要求、开卡与不良信息，资料常显。
- 中间：申请人、申请时间、变更原因及退回/确认信息，区分开卡资料和变更申请。
- 下方：一张表按行稳定键联合原配方、申请配方和确认配方；删除行仍可追溯，重复助剂代码不会合并。
- 配置同时展示比例、算法、单位、阶段、代码、工艺和 pH。只突出真正变化的字段；未添加/删除明确标识，零比例不当成删除。
- 尚未选择确认方案时不显示空白确认配方；选择原配方/申请配方或编辑后才显示完整确认配置。
- 编辑支持新增、移除与恢复助剂，算法联动单位，字段完整保存。沿用现有审核、复样与版本校验。
- 待变更显示退回原因，已确认显示最终结果及确认人时间。不能确认尚未完成复样的申请配方。
- 弹窗随内容撑开，限制最大高度并固定底部操作，窄屏表格自身滚动。
- 不替换其他模块，不改变已有用户记录；缺失流程卡资料显示未记录或 —。
