# 试样管理工作台首页视觉规范设计

## 意图

统一试样管理工作台首页的字体、标题、数字、间距、卡片和表格层级，解决当前同一页面字号与留白规则不一致的问题。首页面向办公室电脑近距离使用，保持信息密度，同时提升阅读稳定性。

## 设计依据

首页直接继承项目现有“组件规范”和 `sampling-ant-design` 视觉契约，不建立第二套设计语言。

- 主色：`#1677FF`
- 成功：`#52C41A`
- 警告：`#FAAD14`
- 错误：`#FF4D4F`
- 主文字：`#1F1F1F`
- 次文字：`#595959`
- 边框与分割线：`#F0F0F0`
- 页面背景：`#F5F5F5`
- 卡片背景：`#FFFFFF`

## 目标

- “变更、待办事项、进度、超时、统计”使用同一套标题层级。
- 待办名称、表头、正文、辅助文字和核心数字之间有稳定的尺寸关系。
- 卡片标题栏、内容边距、圆角、边框和间距统一。
- 保持办公室电脑下一屏展示较多信息，不采用大屏式超大字号。
- 保持现有业务结构、卡片顺序、数据口径和操作入口不变。
- 延续当前窄屏单列规则，不增加页面级横向滚动。

## 非目标

- 不调整顶部导航、侧边菜单和多页签结构。
- 不修改数据计算、业务状态、跳转目标或刷新逻辑。
- 不重新设计图表类型和统计口径。
- 不新增主题、暗色模式或第三方样式库。

## 采用的视觉方案

采用“项目原生 A”：标准 Ant Design 办公密度，并以现有组件规范中的尺寸为准。

### 字体层级

| 层级 | 字号 | 行高 | 字重 | 使用位置 |
|---|---:|---:|---:|---|
| 页面标题 | 20px | 28px | 600 | 独立页面标题；工作台当前无新增页面标题 |
| 模块标题 | 14px | 22px | 600 | 变更、待办事项、打样进度、超时、统计卡片标题 |
| 卡片项目名称 | 14px | 22px | 500 | 配方变更、大货订单审核等待办名称 |
| 正文 | 14px | 22px | 400 | 普通说明和主要文本 |
| 表格文字 | 12px | 20px | 400 | 表头、表格数据、单位 |
| 辅助文字 | 12px | 20px | 400 | 数量单位、更新时间、说明 |
| 次级辅助文字 | 11px | 18px | 400 | 空间非常紧凑的表格补充信息 |
| 核心数字 | 24px | 32px | 600 | 待办数量、主要统计数字 |
| 表格统计数字 | 22px | 30px | 600 | 进度表中的数量 |

短标题不得拆行；确实空间不足时先缩减容器间距，不把标题压缩到小于12px。

### 间距与容器

- 页面内容边距：桌面16px，窄屏12px。
- 首页模块间距：12px。
- 卡片圆角：6px。
- 卡片边框：`1px solid #F0F0F0`。
- 卡片阴影：`0 1px 2px rgba(0,0,0,.03)`，不使用浮夸悬浮阴影。
- 标准卡片内容内边距：16px。
- 模块标题栏：最小高度48px，左右16px。
- 小型统计卡片标题栏：最小高度42px。
- 标题与内容的垂直间距：12px。

## 各模块规范

### 变更与待办事项

- 两个外层模块使用相同标题栏高度和标题字号。
- 内部待办卡片使用6px圆角、浅灰背景、统一边框。
- 待办名称统一为14px / 500，不再使用10–11px的小标题。
- 数字统一为24px / 600；单位“项”为12px、次文字色。
- 变更数字继续使用错误色；普通待办数字使用主文字色。
- 左侧3px主色状态线保留，作为可点击任务卡的识别特征。
- 卡片高度由统一内边距形成，不使用不同卡片各自的固定高度。

### 打样进度与班组对样进度

- 两张进度卡使用相同标题栏高度、表头背景和边框颜色。
- 模块标题14px / 600；标题旁班组选择器和当班信息使用小号控件。
- 表头与普通单元格为12px；左侧业务类型为14px / 500。
- 统计数字为22px / 600。
- 完成使用成功色，超时使用错误色，待处理使用主色或主文字色。
- 打样与对样表格行高统一为48px；对样不可用值继续显示“—”。

### 回修超时与半检超时

- 两张超时卡的标题、数量摘要、表头和数据行完全同构。
- 表头和数据为12px，表头字重600。
- 超时时长使用错误色；流程卡号可保持链接色。
- 数据行高度44px；空状态使用12px次文字色。
- 内部允许纵向滚动，但不得产生页面级横向滚动。

### 底部统计卡片

- 四张卡片标题统一为14px / 600，说明文字统一为12px。
- 卡片内边距统一为16px，图表区域高度统一。
- 图表坐标与标签不小于11px。
- 只使用主色、成功色、警告色和错误色表达状态，减少各卡片自定义颜色。

## 交互与状态

- 可点击卡片保留清晰的 hover、focus-visible 和 active 状态。
- hover 只改变边框、浅背景和轻微阴影，不进行明显位移。
- 图标按钮必须保留可访问名称。
- 禁用、空状态和不可用数值使用次文字色，不能与正常数据竞争视觉注意力。

## 响应式规则

- 大于850px：保持当前双列进度/超时布局和单行待办布局。
- 小于等于850px：业务模块单列排列；变更与待办分行。
- 小于等于700px：底部统计卡片单列。
- 窄屏优先调整网格列数和内边距，不缩小核心正文到12px以下。

## 考虑过的方案

### 通用 Ant Design 方案

使用16px模块标题、14px表格、8px圆角和16px模块间距。可读性较强，但会与项目已有组件规范产生第二套尺寸体系，因此未采用。

### 高密度操作台方案

使用13px正文、11px辅助文字和40px表格行高。单屏信息更多，但无法解决当前文字偏小和层级不清的问题，因此未采用。

### 项目原生 A（采用）

复用项目组件规范的20/14/12字号体系、6px圆角、12px间距和16px内边距，在保持密度的同时统一现有页面。

## 验收标准

- 所有首页模块标题在计算样式中均为14px / 600。
- 待办名称不小于14px，核心数量为24px。
- 进度表的普通文字为12–14px，统计数字为22px。
- 卡片圆角均为6px，模块间距均为12px。
- 两张进度卡和两张超时卡分别具有一致的标题栏、表头和行高。
- 桌面端不出现意外换行；820px宽度无页面级横向滚动。
- 原有按钮、跳转、班组筛选、刷新和数据内容保持可用。
