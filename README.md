# 航民股份四车间 · 试样管理

参考提供的 9 张截图制作的纯前端应用，使用 React 19、TypeScript、Ant Design 5 和 Vite。

## 启动

```sh
npm install
npm run dev
```

访问 http://localhost:5173 。

## 构建

```sh
npm run build
npm run preview
```

构建文件位于 `dist/`，可以放入任何静态网站服务器，支持相对资源路径。

## 页面与交互

- 工作台：待办入口、班组切换、人员任务卡片。
- 打样：任务分类、配方录入、染助剂增删、比例编辑、配方带入、本地保存。
- 抄样：条件查询、历史配方详情抽屉、配方编辑。
- 对样：模拟流程卡扫描、样品对比、通过与退回。
- 配方审核：条件筛选、配方详情、打样过程、基础信息、审核、浏览器打印。
- 配方变更：展示被退回的配方。
- 打样进度：任务筛选、多选、详情。
- 配方查询：记录选择、配方与流程卡联动、编辑与打印。

使用内置演示数据，配方编辑、审核状态和打样配方保存至 localStorage；未连接后端。滴液、交接班等业务动作为演示反馈。截图未展示的外围模块提供空状态页面。

## 染色工艺审核

入口：顶部“生产管理” → 左侧“工艺审核 / 染色工艺审核”。

包含流程卡资料、减量/中和/染色工艺切换、阶段新增与删除、工艺模板选择、温度/速率/时间/说明编辑、总时长自动汇总、历史工艺查询及引用、染色配方表和审核确认。工艺数据与审核状态使用 `lab-dye-process` 本地存储。编辑已审核工艺会将其恢复为待审状态。初始染色工艺 7 个步骤，总时长 92 分钟。

## 主管试样工作台（一屏总览）

工作台只展示提醒与统计，不提供审核、分配、配方编辑等业务操作。

- 顶部四类待办：大货订单审核、预打样订单审核、任务分配、配方确认。
- 分组柱状图：按大货、回修、复样、预打样四类，展示待分配、已分配、进行中和超时数量。所有数据随班组筛选更新。
- 右侧异常提醒：超时任务、多次退回、带布未完成、二次加料流程卡。每类展示数量及优先关注记录，通过入口查看。
- 二次加料指累计加料至少 2 次，按流程卡号去重；卡片展示流程卡号、加料次数及负责人。
- 已分配包含进行中和待确认；超时与其他状态交叉统计，不能相加。
- 布局高度跟随浏览器视口，不出现工作台纵向滚动条。小高度窗口精简异常记录预览，保留所有异常类别与数量。

本次不新增跳转目标页面：配方确认沿用已有“配方审核”页面，任务统计沿用“打样进度”页面；其他业务只保留入口提示，不实现新页面。工作台使用 `lab-workbench-v1` 本地演示数据，和旧截图页面的演示数据独立。
